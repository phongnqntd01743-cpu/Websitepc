# PCForge - PC Builder & Components Store

Demo website for the FPT Polytechnic "Lập trình cơ sở với Javascript" Assignment.

## Chạy project
Mở `index.html` bằng trình duyệt hoặc dùng VS Code Live Server.

## Chức năng
- Product data bằng array/object
- New / Hot / Sale
- Category
- Search / Filter / Sort
- JavaScript slider
- Countdown
- Product detail
- Cart: add/remove/quantity
- LocalStorage cart
- Checkout validation
- PC Builder:
  - **Mô phỏng Thùng PC 3D thời gian thực (Three.js)**:
    - Hiển thị mô hình thùng PC và từng linh kiện (Mainboard, CPU, Tản nhiệt khí / AIO nước, RAM, Card đồ họa GPU, SSD M.2, HDD, Nguồn PSU, Dây cáp).
    - Tương tác xoay 360°, phóng to/thu nhỏ soi chi tiết linh kiện.
    - Đèn LED ARGB đổi màu và quạt quay khi hệ thống được cấp nguồn.
    - Chức năng tháo / lắp kính cường lực trong suốt.
    - Hiệu ứng lắp ráp động (animation) và highlight linh kiện khi chọn.
    - Khung ma (Ghost box) định vị các vị trí linh kiện còn thiếu.
    - Cảnh báo tương thích hiển thị viền đỏ trực tiếp trên mô hình 3D.
- Compatibility checker (Socket, RAM type, GPU length, PSU wattage)
- Save / Load Build bằng LocalStorage
- Add Build to Cart
- Responsive UI & Dark Mode
